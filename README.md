## 🍔 Sobre a Loja
A **Burguer Mania** é uma lanchonete virtual simples. O objetivo do projeto é rodar um simulador de carrinho de compras de forma rápida através do navegador.

### Produtos Disponíveis:
* **Hambúrguer:** R$ 20,00  
* **Batata Frita:** R$ 10,00  
* **Refrigerante:** R$ 5,00  

## 🛠️ Tecnologias
* HTML5, CSS3 e JavaScript básicos.

## 🚀 Como Executar
Basta abrir o arquivo `index.html` no seu navegador de internet.

## 🧪 Testes Realizados
* Digitei 1 para cada produto e o total deu R$ 35,00 corretamente.
* Digitei 0 para tudo e o sistema disparou a mensagem avisando que nada foi selecionado.

## 🧠 Dificuldade e Aprendizado
A maior dificuldade foi entender como converter o texto digitado no prompt para número. Aprendi que o comando `Number()` resolve esse problema perfeitamente.
